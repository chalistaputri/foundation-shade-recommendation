# Foundation Shade Recommendation App

A Streamlit app to recommend foundation shades based on **skin tone** and **brand**.  
Built with Python, Pandas, and Streamlit.

---

## Project Overview
Foundation shade matching can be tricky. This app helps users filter products by:
- Skin tone category (Light, Medium, Dark, Other)
- Brand preference
- Optional budget filter (if price data available)

It also displays product details and preview images from the dataset.
